# ぶたごりら学習ポータル 統合版

GitHub Pagesで、基本情報アプリと英単語アプリを同じサイト内で使うための構成です。

## 構成

- `/index.html` トップメニュー
- `/fe/` 基本情報技術者試験 一問一答
- `/english/` TOEIC600 英単語3000

## 公開後のURL例

- トップ: `https://butagorilla1182.github.io/fe-quiz/`
- 基本情報: `https://butagorilla1182.github.io/fe-quiz/fe/`
- 英単語: `https://butagorilla1182.github.io/fe-quiz/english/`

## GitHubへの入れ方

1. ZIPを解凍
2. 中身をGitHubリポジトリのrootへアップロード
3. 既存ファイルは上書き
4. Settings → Pages が main / root になっていることを確認
5. 数分待ってトップURLを開く

## 注意

Publicリポジトリに置く場合、個人情報・職場情報・内部資料は入れないでください。
